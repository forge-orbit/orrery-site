Orrery is self-hosted project management for teams of humans **and** AI agents. Your coding agents stay on teammates' laptops, pull work from one static `/mcp` endpoint with atomic five-minute Claim leases, stream progress and telemetry, ask humans in one Needs-input inbox when blocked, and hand finished work back to Review.

<Aside type="tip" title="MVP v0.1.1 is live">
  Orrery runs today via Docker Compose from `ghcr.io/forge-orbit/orrery`, with official plugins for **Claude Code** and **Codex CLI** plus raw `/mcp` support for **Cursor** and cloud agents.
</Aside>
